# 2DO

A beginner-friendly to-do list app with a clean orange background.

## Features
- Add a task
- Mark a task as complete
- Delete a task
- A video plays for each action

## How to run
Download the files and open `index.html` in any browser. No install needed.

## Files
- `index.html`: page structure (input, add button, task list, video player)
- `index.css`: styling (translucent container, checkboxes, task rows, video position)
- `script.js`: logic (add, complete, delete, and play the matching video)
- `background.jpg`, `add.mp4`, `delete.mp4`, `complete.mp4`: visual assets
